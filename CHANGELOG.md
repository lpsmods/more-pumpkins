# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.1] (1.21.132) - 1/18/2026

### General

- Added `Creator` tab to the guide book.
- Added public API to add your own carving knife recipes.

## [2.0.0] (1.21.101) - 10/24/2025

> NOTE: This update is not compatible with older versions.

### General

- Updated for 1.21.114
- Now requires Assets+ 2.0.0
- All pumpkins have been moved to the Nature tab and are in their own groups.
- Renamed skeleton pumpkin to skull.
- Removed stonecutter recipes.

### New

- Added guide book.
- Added carving knives.
- Added pale pumpkin along with all carved and lit variants.
- Added redstone and copper variants.
- New patterns

## [1.2.0] (1.19.80) - 5-22-2023

### General

- Updated for 1.19.80
- Requires Assets Plus v1.4.0
- Blocks now use unit_cube instead of custom geometry
- You can now craft all blocks by placing any carved, jack o' lantern, or soul jack o' lantern in a stonecutter.

## [1.1.0] (1.19.40)

### General

- Minimum version 1.19.40
- Removed give functions, you can obtain all blocks via the creative inventory.
